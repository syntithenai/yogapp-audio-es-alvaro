# yogapp-audio-es-alvaro

https://syntithenai.github.io/yogapp-audio-es-alvaro/v1/

Published by `apps/yoga/scripts/publish-voice-files.sh` in the yogapp repo.
The phone app downloads the same clips as a zip from
https://syntithenai.github.io/yogapp-audio-es-alvaro/v1/es-alvaro.zip
